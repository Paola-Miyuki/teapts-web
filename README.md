# teapts-web
Versão web do sistema TEA-PTS


### Padrão de Commits

Este projeto adota o padrão Conventional Commits.

Estrutura:

```text
<tipo>: <descrição>
```

Exemplos:

```text
feat: adiciona integração com endpoint de contatos
fix: corrige tratamento de timeout da API do HubSpot
refactor: simplifica fluxo de processamento de webhooks
test: adiciona testes para serviço de deals
docs: atualiza instruções de desenvolvimento
chore: atualiza dependências do projeto
```

Tipos recomendados:

| Tipo     | Descrição                           |
| -------- | ----------------------------------- |
| feat     | Nova funcionalidade                 |
| fix      | Correção de bug                     |
| refactor | Refatoração sem alteração funcional |
| test     | Inclusão ou ajuste de testes        |
| docs     | Alterações de documentação          |
| chore    | Tarefas de manutenção               |
| ci       | Alterações de pipelines             |
| build    | Alterações relacionadas à build     |
